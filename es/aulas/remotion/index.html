Clase 5 · 15 min

Remotion: frame, interpolate, spring y cuándo elegir React

Remotion hace lo mismo que HyperFrames con otro lenguaje: cada fotograma es un componente React que recibe el número del fotograma. interpolate mapea fotogramas en valores y spring le da física a la entrada. En esta clase renderizas la misma idea de la clase 2 en React, lees la licencia y decides cuándo vale más cada motor.

Empezar la clase

En esta clase vas a

  1. 1Composition: id, fps, duración en fotogramas y tamaño
  2. 2interpolate con clamp y easing; spring con amortiguación
  3. 3La licencia de Remotion en oct/2026
  4. 4HyperFrames o Remotion: el criterio de elección

Objetivo: renderizar una composición Remotion con interpolate y spring y decidir entre Remotion y HyperFrames.

02 · La composición en React

Título con spring, filete y subtítulo con interpolate. El package.json fija remotion 4.0.537 (npm, 19/10/2026).

Archivo · kit/remotion/src/index.tsx
import {AbsoluteFill, Composition, Easing, interpolate, registerRoot, spring, useCurrentFrame, useVideoConfig} from 'remotion';

// Todo es función del fotograma actual: el mismo fotograma dibuja siempre la misma imagen.
const Abertura: React.FC = () => {
  const frame = useCurrentFrame();
  const {fps} = useVideoConfig();
  // spring: entra con física (0 → 1), empezando en el fotograma 10
  const entra = spring({frame: frame - 10, fps, config: {damping: 200}});
  // interpolate: mapea fotogramas a valores; clamp sujeta el valor en los extremos
  const apoio = interpolate(frame, [30, 50], [0, 1], {extrapolateLeft: 'clamp', extrapolateRight: 'clamp'});
  const barra = interpolate(frame, [20, 60], [0, 640], {
    extrapolateLeft: 'clamp',
    extrapolateRight: 'clamp',
    easing: Easing.inOut(Easing.cubic),
  });
  return (
    <AbsoluteFill style={{background: '#0c0c10', justifyContent: 'center', paddingLeft: 200, fontFamily: 'system-ui, sans-serif'}}>
      <h1 style={{color: '#f4f4f5', fontSize: 120, lineHeight: 1.1, margin: 0, opacity: entra, transform: `translateY(${(1 - entra) * 60}px)`}}>
        Vídeo é React
      </h1>
      <div style={{width: barra, height: 6, background: '#e9b949', margin: '36px 0'}} />
      <p style={{color: '#a1a1aa', fontSize: 48, margin: 0, opacity: apoio}}>Um componente, um quadro, um MP4.</p>
    </AbsoluteFill>
  );
};

const Raiz: React.FC = () => (
  <Composition id="Abertura" component={Abertura} durationInFrames={150} fps={30} width={1920} height={1080} />
);

registerRoot(Raiz);

04 · Licencia y elección

Qué leer antes de usarlo en un proyecto de empresa.

1. Licencia hoy

El LICENSE.md de Remotion libera el uso gratuito para personas físicas, organizaciones sin fines de lucro y empresas de hasta 3 personas; por encima de eso, la empresa necesita la licencia de pago.

HyperFrames es Apache-2.0: uso libre, incluso comercial.

2. Lo que viene

La página de migración de Remotion 5.0 menciona un cambio de licencia (los contratistas pasarían a contar en el equipo). El 19/10/2026 la 5.0 no había salido y la regla no estaba confirmada: vuelve a leer el LICENSE.md cuando actualices.

3. Cuándo React

Equipo que ya escribe React, componentes reutilizados de una app, datos pasados por props, video generado dentro de un producto en React.

4. Cuándo HTML

Pieza que un agente escribe desde cero, sin build; check con layout y contraste integrados; snapshot de fotogramas; TTS y transcripción locales en el mismo CLI (clase 7).
