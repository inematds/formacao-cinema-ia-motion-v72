Clase 8 · 20 min

Tu pieza: apertura de 15 s en 16:9 y 9:16, renderizada y verificada

Es hora de juntar todo en una pieza que uses: una apertura de 15 s con tu DESIGN.md, en los dos formatos que piden las redes. El 9:16 no sale del 16:9 con una opción de render: es otra composición que reutiliza el CSS y la coreografía. En esta clase entregas las dos, verificadas por el kit, y armas el plan con fechas.

Empezar la clase

En esta clase vas a

  1. 1Un proyecto, dos composiciones: index.html y formatos/vertical.html
  2. 2CSS y coreografía compartidos, solo cambia la medida
  3. 3Cola de renders: uno por vez y retomar solo lo que falló
  4. 4El mapa del curso y tu plan con fechas

Objetivo: entregar una apertura de 15 s en 16:9 y 9:16, con el DESIGN.md, verificada por el kit en los dos formatos.

Archivo · kit/exemplos/a8-abertura/abertura.js
// La misma coreografía en los dos formatos: solo la distancia del cabezal de lectura depende del ancho.
window.criaAbertura = function () {
  const root = document.getElementById("root");
  const largura = Number(root.dataset.width);
  const corrida = largura * 0.8 - 18; // del comienzo al final del riel (80% del ancho)
  const tl = gsap.timeline({ paused: true });
  tl.fromTo("#trilho", { scaleX: 0 }, { scaleX: 1, duration: 1.2, ease: "power2.inOut" }, 0.4);
  tl.fromTo("#cabeca", { opacity: 0 }, { opacity: 1, duration: 0.3 }, 1.4);
  tl.fromTo("#rotulo", { y: 24, opacity: 0 }, { y: 0, opacity: 1, duration: 0.6, ease: "power2.out" }, 2.0);
  tl.fromTo("#cabeca", { x: 0 }, { x: corrida, duration: 9, ease: "power1.inOut" }, 2.0);
  tl.fromTo("#titulo", { y: 50, opacity: 0 }, { y: 0, opacity: 1, duration: 0.8, ease: "power3.out" }, 4.0);
  tl.fromTo("#apoio", { y: 30, opacity: 0 }, { y: 0, opacity: 1, duration: 0.7, ease: "power2.out" }, 7.5);
  // de 11 s a 15 s el fotograma principal se sostiene (regla del DESIGN.md: el final se sostiene al menos 1,5 s)
  return tl;
};

El render del 9:16 usa -c formatos/vertical.html. El vertical.html es el index.html con la raíz en 1080×1920, la clase vertical y las rutas ../abertura.css y ../abertura.js.

✗  Output resolution incompatible

   outputResolution portrait (1080×1920) does not match the aspect ratio of the composition (1920×1080). The composition is landscape, so use --resolution landscape instead.

La opción --resolution cambia la resolución dentro de la misma proporción (por ejemplo, 4K). Pasar de 16:9 a 9:16 es cambiar el encuadre: otra composición.

En el primer render, el 9:16 partió el título en "Motion por" / "código": falla 2 de la clase 3. La corrección fue unir las dos últimas palabras con &nbsp; en el HTML ("por&nbsp;código"). Solo apareció mirando los fotogramas.

04 · La cola de renders

En una máquina común, el render va de a uno. Ejecuta, interrumpe y ejecuta de nuevo: solo lo que faltó vuelve a la cola.

fila/

Simulación en el navegador: nada se renderiza de verdad. La falla es intencional, para mostrar que solo vuelve la etapa que falló.
