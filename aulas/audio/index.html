Aula 7 · 18 min

Áudio e legenda no código: narração local, trilha e karaokê

O mesmo CLI que renderiza também fala e escuta, tudo na sua máquina: gera a narração com uma voz local, transcreve palavra por palavra com o tempo de cada uma e entrega isso à composição. Nesta aula você monta o lado técnico do som: narração, uma trilha de ensaio e a legenda karaokê que acende cada palavra na hora em que ela é dita.

Começar a aula

Nesta aula você vai

  1. 1tts: texto em WAV com a voz Kokoro, sem nuvem
  2. 2transcribe: o tempo de cada palavra num transcript.json
  3. 3<audio> com id, data-start e data-volume na composição
  4. 4Legenda de até três palavras que acende no tempo da fala

Objetivo: gerar narração local, tirar o tempo de cada palavra e renderizar um vídeo com áudio e legenda karaokê.

A segunda linha é a duração da narração em segundos. O número de palavras confere o transcript, não o texto: confira as palavras abrindo o transcript.json.

O modelo padrão do transcribe no 0.8.176 é o small.en, só inglês. Para português, passe -m small -l pt: o small multilíngue não aparece na lista do --help (tiny.en, base.en, small.en, medium.en, large-v3), mas funcionou nesta máquina (captura ao lado). E com --engine auto (padrão) o CLI usa o Parakeet se ele estiver instalado e cobrir o idioma; sem ele, o whisper.cpp.

Arquivo · kit/karaoke.py
#!/usr/bin/env python3
"""karaoke.py — transforma o transcript.json (palavra + tempo) em legendas.js para a composição.

Uso:  python3 karaoke.py transcript.json --inicio 0.5 --por-linha 3 > legendas.js

--inicio     segundos em que a narração começa no vídeo (o data-start do <audio>)
--por-linha  palavras por legenda (padrão 3)
Imprime na saída de erro: "palavras: N · legendas: M".
"""
import argparse
import json
import sys


def main():
    a = argparse.ArgumentParser()
    a.add_argument("transcript")
    a.add_argument("--inicio", type=float, default=0.0)
    a.add_argument("--por-linha", type=int, default=3)
    o = a.parse_args()
    palavras = json.load(open(o.transcript, encoding="utf-8"))
    linhas = []
    for i in range(0, len(palavras), o.por_linha):
        grupo = palavras[i:i + o.por_linha]
        linhas.append({
            "inicio": round(grupo[0]["start"] + o.inicio, 3),
            "fim": round(grupo[-1]["end"] + o.inicio, 3),
            "palavras": [{"t": p["text"], "inicio": round(p["start"] + o.inicio, 3)} for p in grupo],
        })
    # cada legenda sai 0,15 s depois da última palavra, mas nunca depois que a próxima entra
    for atual, prox in zip(linhas, linhas[1:] + [None]):
        atual["fim"] = round(min(atual["fim"] + 0.15, prox["inicio"]) if prox else atual["fim"] + 0.15, 3)
    print("window.LEGENDAS = " + json.dumps(linhas, ensure_ascii=False) + ";")
    print(f"palavras: {len(palavras)} · legendas: {len(linhas)}", file=sys.stderr)


if __name__ == "__main__":
    main()

O conferidor com --audio reprova vídeo sem faixa de som. A trilha é só um acorde gerado pelo FFmpeg para o ensaio; a sua entra no lugar do trilha.wav.

Na primeira versão, cada legenda ficava 0,15 s depois da última palavra mesmo quando a próxima já tinha entrado: duas legendas se sobrepunham no quadro. O karaoke.py agora fecha cada legenda no máximo quando a próxima abre. Só apareceu olhando os quadros.
