Your piece: a 15 s opening in 16:9 and 9:16, rendered and checked

Time to put it all together into a piece you actually use: a 15 s opening with your DESIGN.md, in the two formats social networks ask for. File · kit/exemplos/a8-abertura/abertura.js
// The same choreography in both formats: only the playhead's travel distance depends on the width.
window.criaAbertura = function () {
  const root = document.getElementById("root");
  const largura = Number(root.dataset.width);
  const corrida = largura * 0.8 - 18; // from the start to the end of the track (80% of the width)
  const tl = gsap.timeline({ paused: true });
  tl.fromTo("#trilho", { scaleX: 0 }, { scaleX: 1, duration: 1.2, ease: "power2.inOut" }, 0.4);
  tl.fromTo("#cabeca", { opacity: 0 }, { opacity: 1, duration: 0.3 }, 1.4);
  tl.fromTo("#rotulo", { y: 24, opacity: 0 }, { y: 0, opacity: 1, duration: 0.6, ease: "power2.out" }, 2.0);
  tl.fromTo("#cabeca", { x: 0 }, { x: corrida, duration: 9, ease: "power1.inOut" }, 2.0);
  tl.fromTo("#titulo", { y: 50, opacity: 0 }, { y: 0, opacity: 1, duration: 0.8, ease: "power3.out" }, 4.0);
  tl.fromTo("#apoio", { y: 30, opacity: 0 }, { y: 0, opacity: 1, duration: 0.7, ease: "power2.out" }, 7.5);
  // from 11 s to 15 s the main frame holds (DESIGN.md rule: the ending holds for at least 1.5 s)
  return tl;
};

The 9:16 render uses -c formatos/vertical.html. vertical.html is index.html with the root at 1080×1920, the vertical class, and the paths ../abertura.css and ../abertura.js.

✗  Output resolution incompatible

   outputResolution portrait (1080×1920) does not match the aspect ratio of the composition (1920×1080). The composition is landscape, so use --resolution landscape instead.

The --resolution option changes the resolution within the same aspect ratio (for example, 4K). Going from 16:9 to 9:16 means changing the framing: a different composition.

On the first render, the 9:16 broke the title into "Motion por" / "código": failure 2 from lesson 3. The fix was to tie the last two words together with &nbsp; in the HTML ("por&nbsp;código"). It only showed up by looking at the frames.

04 · The render queue

On an ordinary machine, renders run one at a time. Run it, interrupt it and run it again: only what was left over goes back in the queue.

fila/

rodando/

pronto/

falhou/

Browser simulation: nothing really renders. The failure is on purpose, to show that only the step that failed goes back.
