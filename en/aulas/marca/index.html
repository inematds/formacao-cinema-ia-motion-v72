Lesson 4 · 15 min

Brand system and motion philosophy: the DESIGN.md for your video

Without a written rule, every request to the agent brings a new color and a different motion, and the pieces don't look like they're from the same brand. DESIGN.md is the file the agent reads before composing: colors, fonts, how things move, and what's forbidden. In this lesson you write yours and fail any off-brand color with one command.

Start the lesson

In this lesson you will

  1. 1The four sections: Colors, Typography, Motion, and Forbidden
  2. 2Tokens: the color is born in DESIGN.md and becomes a CSS variable
  3. 3Motion philosophy written as a rule with a number
  4. 4The checker that catches the color the agent made up

Goal: write your video's DESIGN.md and prove the composition uses only its colors and rules.

02 · An example DESIGN.md and the composition that obeys it

The example uses INEMA's dark palette. Swap in your brand's colors, keeping the four sections.

File · kit/exemplos/a4-marca/DESIGN.md
# DESIGN.md — example video (Motion by code course, INEMA.CLUB)

One sentence: calm dark background, one idea at a time, light instead of color; yellow appears only as a detail.

## Cores
- fundo: #0c0c10
- superfície: #1c1c22
- linha: #3f3f47
- texto: #f4f4f5
- texto secundário: #a1a1aa
- destaque (só detalhe: um filete, um ponto, a cabeça de leitura): #e9b949

## Tipografia
- Títulos: sem serifa do sistema, peso 700, altura de linha 1,1, no máximo 6 palavras.
- Apoio: sem serifa do sistema, peso 400, 48 px em 1920x1080.
- Nenhuma palavra sozinha na última linha.

## Movimento
- Entrada de 0,5 a 0,8 s com power2.out ou power3.out; saída mais curta que a entrada, com power2.in.
- Uma coisa se move por vez; a próxima começa quando a anterior já assentou.
- Todo texto fica pelo menos 1,2 s parado e legível.
- Nada em velocidade constante (ease "none" só em barra de progresso).
- O quadro principal (título ou marca) segura pelo menos 1,5 s no fim.

## Proibido
- Cor que não está em "Cores", neon, brilho forte, gradiente colorido.
- Logo desenhado de memória: logo só do arquivo da marca.
- Math.random e Date.now na composição.

03 · Check the brand with one command

The conferir-design.py reads the four sections and looks in the composition for every hex color that is not in Cores.

Terminal · check DESIGN.md and the check
K=~/projetos/formacao-cinema-ia-motion-v72/kit
export HYPERFRAMES_NO_TELEMETRY=1 NO_COLOR=1
E=${TMPDIR:-/tmp}/ensaio-motion/a4; rm -rf "$E"; mkdir -p "$E"
cp -r "$K/exemplos/a4-marca" "$E/marca"; cd "$E/marca"
python3 "$K/conferir-design.py" DESIGN.md index.html; echo "saída: $?"
npx -y hyperframes@0.8.176 check 2>&1 | grep -E "Check passed|✗|WCAG"
Terminal · the error: the agent "improved" the highlight
K=~/projetos/formacao-cinema-ia-motion-v72/kit
cd ${TMPDIR:-/tmp}/ensaio-motion/a4/marca
sed -i 's/--destaque: #e9b949/--destaque: #ff3366/' index.html   # the agent "improved" the highlight
python3 "$K/conferir-design.py" DESIGN.md index.html; echo "saída: $?"

One line is enough to get the pink into the video. The checker tells you which color and on which line, and exits with code 1 so it can stop the render in a script.

04 · How the agent uses the file

Three habits that make DESIGN.md worth it.

1. Cite it in the R

The RISE request starts with "read the DESIGN.md in this folder" (lesson 3).

Without that, the agent only reads it if it remembers.

2. Put it in the gate

Run conferir-design.py together with the check, in a single script.

Code 1 from either one stops everything.

Gatepython3 conferir-design.py DESIGN.md index.html && npx hyperframes@0.8.176 check

3. Change it in the file

Don't like the yellow? Change it in DESIGN.md and ask the agent to apply it.

A change made directly in a piece disappears on the next one.
