Lesson 5 · 15 min

Remotion: frame, interpolate, spring, and when to pick React

Remotion does the same thing as HyperFrames in another language: each frame is a React component that receives the frame number. interpolate maps frames to values and spring gives physics to an entrance. In this lesson you render the same idea from lesson 2 in React, read the license, and decide when each engine is worth more.

Start the lesson

In this lesson you will

  2. 2interpolate with clamp and easing; spring with damping
  3. 3The Remotion license in Oct 2026
  4. 4HyperFrames or Remotion: the criteria for choosing

Goal: render a Remotion composition with interpolate and spring and choose between Remotion and HyperFrames.

02 · The composition in React

Title with spring, rule, and subtitle with interpolate. The package.json pins remotion 4.0.537 (npm, 10/19/2026).

File · kit/remotion/src/index.tsx
import {AbsoluteFill, Composition, Easing, interpolate, registerRoot, spring, useCurrentFrame, useVideoConfig} from 'remotion';

// Everything is a function of the current frame: the same frame always draws the same image.
const Abertura: React.FC = () => {
  const frame = useCurrentFrame();
  const {fps} = useVideoConfig();
  // spring: enters with physics (0 → 1), starting at frame 10
  const entra = spring({frame: frame - 10, fps, config: {damping: 200}});
  // interpolate: maps frames to values; clamp holds the value at the ends
  const apoio = interpolate(frame, [30, 50], [0, 1], {extrapolateLeft: 'clamp', extrapolateRight: 'clamp'});
  const barra = interpolate(frame, [20, 60], [0, 640], {
    extrapolateLeft: 'clamp',
    extrapolateRight: 'clamp',
    easing: Easing.inOut(Easing.cubic),
  });
  return (
    <AbsoluteFill style={{background: '#0c0c10', justifyContent: 'center', paddingLeft: 200, fontFamily: 'system-ui, sans-serif'}}>
      <h1 style={{color: '#f4f4f5', fontSize: 120, lineHeight: 1.1, margin: 0, opacity: entra, transform: `translateY(${(1 - entra) * 60}px)`}}>
        Vídeo é React
      </h1>
      <div style={{width: barra, height: 6, background: '#e9b949', margin: '36px 0'}} />
      <p style={{color: '#a1a1aa', fontSize: 48, margin: 0, opacity: apoio}}>Um componente, um quadro, um MP4.</p>
    </AbsoluteFill>
  );
};

const Raiz: React.FC = () => (
  <Composition id="Abertura" component={Abertura} durationInFrames={150} fps={30} width={1920} height={1080} />
);

registerRoot(Raiz);

04 · License and choice

What to read before using it in a company project.

1. License today

Remotion's LICENSE.md allows free use for individuals, nonprofit organizations, and companies of up to 3 people; above that, the company needs the paid license.

HyperFrames is Apache-2.0: free to use, including commercially.

2. What's coming

The Remotion 5.0 migration page mentions a license change (contractors would start counting toward the team). On 10/19/2026, 5.0 hadn't been released and the rule wasn't confirmed: reread LICENSE.md when you update.

3. When to pick React

A team that already writes React, components reused from an app, data passed through props, video generated inside a React product.

4. When to pick HTML

A piece that an agent writes from scratch, with no build; a check with built-in layout and contrast; frame snapshots; local TTS and transcription in the same CLI (lesson 7).
