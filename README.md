# Motion por código com agente

Curso 3 de 6 da **Formação Cinema com IA** do INEMA.CLUB (conteúdo aberto e gratuito), no formato INEMA Learning v7.2, em português, inglês e espanhol.

- Curso: https://inematds.github.io/formacao-cinema-ia-motion-v72/ ([EN](https://inematds.github.io/formacao-cinema-ia-motion-v72/en/) · [ES](https://inematds.github.io/formacao-cinema-ia-motion-v72/es/))
- Kit: [`kit/`](kit/) — os blocos de terminal das aulas (`kit/blocos/`), as saídas capturadas (`kit/saidas/`), os exemplos (`kit/exemplos/`) e os conferidores (`conferir.py`, `conferir-design.py`, `costura.sh`, `comparar-quadros.sh`, `karaoke.py`).

Clone em `~/projetos` para os blocos funcionarem como estão:

```bash
git clone https://github.com/inematds/formacao-cinema-ia-motion-v72 ~/projetos/formacao-cinema-ia-motion-v72
```

Requisitos: Node 22+, FFmpeg, Python 3, git. Tudo renderiza localmente (HyperFrames 0.8.176, Remotion 4.0.537), sem API e sem crédito.

Conteúdo em `conteudo/<lang>/`; o HTML é gerado por `gerar.py` (não edite o HTML à mão).
